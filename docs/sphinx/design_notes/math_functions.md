# Mathematical Functions to be Implemented

## Basic Functions

Basic functions in `<cmath>` header in C++:

| Function                                                        | Name in FuncSketch | In C++        | In Python     |
| :-------------------------------------------------------------- | :----------------- | :------------ | :------------ |
| Absolute value function $\|x\|$                                 | `abs`              | `std::abs`    | `math.fabs`   |
| Exponential function $e^x$                                      | `exp`              | `std::exp`    | `math.exp`    |
| 2 raised to the given power $2^x$                               | `exp2`             | `std::exp2`   | `math.exp2`   |
| Exponential function minus 1 $e^x - 1$                          | `expm1`            | `std::expm1`  | `math.expm1`  |
| Natural logarithm function $\log{x}$                            | `log`              | `std::log`    | `math.log`    |
| Natural logarithm of 1 plus x $\log{(1+x)}$                     | `log1p`            | `std::log1p`  | `math.log1p`  |
| Common logarithm function $\log_{10}{x}$                        | `log10`            | `std::log10`  | `math.log10`  |
| Base 2 logarithm function $\log_{2}{x}$                         | `log2`             | `std::log2`   | `math.log2`   |
| Power function $x^y$                                            | `pow`              | `std::pow`    | `math.pow`    |
| Square root function $\sqrt{x}$                                 | `sqrt`             | `std::sqrt`   | `math.sqrt`   |
| Cubic root function $\sqrt[3]{x}$                               | `cbrt`             | `std::cbrt`   | `math.cbrt`   |
| Sine function $\sin{x}$                                         | `sin`              | `std::sin`    | `math.sin`    |
| Cosine function $\cos{x}$                                       | `cos`              | `std::cos`    | `math.cos`    |
| Tangent function $\tan{x}$                                      | `tan`              | `std::tan`    | `math.tan`    |
| Arcsine function $\arcsin{x}$                                   | `asin`             | `std::asin`   | `math.asin`   |
| Arccosine function $\arccos{x}$                                 | `acos`             | `std::acos`   | `math.acos`   |
| Arctangent function $\arctan{x}$                                | `atan`             | `std::atan`   | `math.atan`   |
| Arctangent function on two variables                            | `atan2`            | `std::atan2`  | `math.atan2`  |
| Hyperbolic sine function $\sinh{x}$                             | `sinh`             | `std::sinh`   | `math.sinh`   |
| Hyperbolic cosine function $\cosh{x}$                           | `cosh`             | `std::cosh`   | `math.cosh`   |
| Hyperbolic tangent function $\tanh{x}$                          | `tanh`             | `std::tanh`   | `math.tanh`   |
| Hyperbolic arcsine function $\mathrm{asinh}\,{x}$               | `asinh`            | `std::asinh`  | `math.asinh`  |
| Hyperbolic arccosine function $\mathrm{acosh}\,{x}$             | `acosh`            | `std::acosh`  | `math.acosh`  |
| Hyperbolic arctangent function $\mathrm{atanh}\,{x}$            | `atanh`            | `std::atanh`  | `math.atanh`  |
| Error function $\mathrm{erf}\,{x}$                              | `erf`              | `std::erf`    | `math.erf`    |
| Complementary error function $\mathrm{erfc}\,{x}$               | `erfc`             | `std::erfc`   | `math.erfc`   |
| Gamma function $\Gamma{(x)}$                                    | `gamma`            | `std::tgamma` | `math.gamma`  |
| Natural logarithm of the gamma function $\log{\|\Gamma{(x)}\|}$ | `lgamma`           | `std::lgamma` | `math.lgamma` |
| Ceiling function $\lceil{x}\rceil$                              | `ceil`             | `std::ceil`   | `math.ceil`   |
| Floor function $\lfloor{x}\rfloor$                              | `floor`            | `std::floor`  | `math.floor`  |
| Truncation function $\mathrm{trunc}\,{x}$                       | `trunc`            | `std::trunc`  | `math.trunc`  |

- `pow` function has two arguments, but all other functions have one argument.
- All functions will be calculated using floating-point numbers.
