# About

FuncSketch is a graphing calculator
for plotting a wide variety of functions interactively.

## Features

- Interactive graphing of functions powered by a fast C++ backend
- Support for special functions
  - Currently supported:
    Bessel functions,
    beta functions,
    elliptic integrals,
    error functions,
    gamma functions,
    Jacobi elliptic functions,
    Hermite polynomials,
    and more.
  - More special functions will be added in the future.
- Support for numerical integration
