# Release v0.2.0

## Features

- First release with PyPI packages.
  - Wheels are available for `x86_64` architecture.
- Support of complex numbers.
- Support of Bessel functions, Hankel functions and Kelvin functions.
- Added axis titles to plots.

## Improvements

- Updated design of GUI.

## Miscellaneous

- Refactored internal implementation.
- Added benchmarks.
- Added implementation of plot titles internally. This will be made available in configuration options in future releases.
- Changed linters used in Python code.
