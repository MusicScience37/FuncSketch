Function Expressions in FuncSketch
========================================

Function expressions in FuncSketch can be written
as in existing programming languages.
For example, the followings are valid function expressions:

- ``x + 2``
- ``exp(-x * x)``
- ``sin(pi * x) / (pi * x)``

Following pages describe the grammar,
constants and built-in functions in function expressions.
