.. _builtin_constants:

Built-in Constants
=======================

FuncSketch currently provides the following built-in constants
that can be used in function expressions:

Mathematical Constants
----------------------------

.. csv-table::
    :header: "Constant", "Type", "Value", "Description"

    "``e``", "Real", "2.71828...", "Euler's number or Napier's constant (:math:`e`)"
    "``euler_mascheroni``", "Real", "0.57721...", "Euler-Mascheroni constant (:math:`\gamma`)"
    "``golden_ratio``", "Real", "1.61803...", "Golden ratio (:math:`\phi`)"
    "``i``", "Complex", "1i", "Imaginary unit (:math:`i`)"
    "``pi``", "Real", "3.14159...", "Pi (:math:`\pi`)"

Physical Constants
----------------------------

.. csv-table::
    :header: "Constant", "Type", "Value", "Unit", "Description"

    "``avogadro_constant``", "Real", "6.02214076e23", ":math:`\mathrm{mol^{-1}}`", "Avogadro constant (:math:`N_A`)"
    "``boltzmann_constant``", "Real", "1.380649e-23", ":math:`\mathrm{J\,K^{-1}}`", "Boltzmann constant (:math:`k_B`)"
    "``elementary_charge``", "Real", "1.602176634e-19", ":math:`\mathrm{C}`", "Elementary charge (:math:`e`)"
    "``gravitational_constant``", "Real", "6.67430e-11", ":math:`\mathrm{N\,m^2\,kg^{-2}}`", "Gravitational constant (:math:`G`)"
    "``planck_constant``", "Real", "6.62607015e-34", ":math:`\mathrm{J\,s}`", "Planck constant (:math:`h`)"
    "``speed_of_light``", "Real", "299792458", ":math:`\mathrm{m\,s^{-1}}`", "Speed of light in vacuum (:math:`c`)"

.. note::
    Values of the physical constants above are based on the Japanese publication
    "Chronological Scientific Tables 2023" published by Maruzen Publishing Co., Ltd.
    ("理科年表 2023" in Japanese).
